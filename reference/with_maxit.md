# Rebuild an Optimizer With a Different Iteration Budget

Rebuild an Optimizer With a Different Iteration Budget

## Usage

``` r
with_maxit(optimizer, maxit)
```

## Arguments

- optimizer:

  The
  [`optimizer`](https://statmodels7.github.io/optimizers7/reference/optimizer.md).

- maxit:

  The new budget.

## Value

An optimizer of the same class.
