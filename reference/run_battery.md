# Run an Optimizer Over the Battery

The gap from each known minimum, as information rather than as a
verdict.

## Usage

``` r
run_battery(optimizer, problems)
```

## Arguments

- optimizer:

  The
  [`optimizer`](https://statmodels7.github.io/optimizers7/reference/optimizer.md).

- problems:

  A list in the shape
  [`test_problems`](https://statmodels7.github.io/optimizers7/reference/test_problems.md)
  returns.

## Value

A data frame with one row per problem.
