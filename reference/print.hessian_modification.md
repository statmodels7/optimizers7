# Print Method for Hessian Modifications

Print Method for Hessian Modifications

## Arguments

- x:

  A
  [`hessian_modification()`](https://statmodels7.github.io/optimizers7/reference/hessian_modification.md)
  object.

- ...:

  Unused.

## Value

`x`, invisibly.

## Examples

``` r
print(modify_ridge())
#> <hessian_modification> ridge (floor = 1e-08)
```
