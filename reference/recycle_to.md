# Recycle a Length-One Vector, and Reject Any Other Mismatch

Recycle a Length-One Vector, and Reject Any Other Mismatch

## Usage

``` r
recycle_to(v, n, nm)
```

## Arguments

- v:

  A numeric vector.

- n:

  The length wanted.

- nm:

  The argument's name, for the message.

## Value

A numeric vector of length `n`.
